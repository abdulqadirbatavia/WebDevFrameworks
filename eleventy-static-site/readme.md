# 11ty Quiz Game - Modern Web Development Project

## 📋 Project Overview
This is a static website built with **Eleventy (11ty)** demonstrating modern web development practices. The project features a quiz game with multiple categories and responsive design.

## 🚀 Features Implemented
- ✅ **Eleventy Configuration** - Custom `eleventy.config.js`
- ✅ **Nunjucks Templating** - All templates use `.njk` files
- ✅ **Content Collections** - Questions organized as collections
- ✅ **Front Matter** - Metadata in all template files
- ✅ **Layout Reuse** - Single `layout.njk` for consistency
- ✅ **Static Assets** - Professional CSS styling
- ✅ **Build Process** - npm scripts for development and production
- ✅ **Markdown Content** - About page written in Markdown
- ✅ **Pagination** - Individual question pages with pagination

## 🛠 Technical Stack
- **Static Site Generator**: Eleventy (11ty) v2.0.1
- **Templating Language**: Nunjucks
- **Styling**: Modern CSS3 with CSS Grid and Flexbox
- **Build Tool**: Node.js and npm
- **Development Server**: Built-in 11ty server with live reload
