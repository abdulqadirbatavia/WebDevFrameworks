# Web Development & Framework Projects

A collection of web applications and static sites built using modern web frameworks, static site generators (Eleventy / 11ty), template engines (Nunjucks), containerization (Docker), and custom CSS.

## Featured Projects

| Project | Description | Tech Stack |
| :--- | :--- | :--- |
| **Eleventy Static Site** | Fast, pre-rendered knowledge base site utilizing Nunjucks templates, dynamic data routing, and modern CSS variables. | 11ty, Nunjucks, CSS3, Node.js |
| **Ghost CMS Deployment** | Production-ready Content Management System configured and deployed via Docker containers. | Ghost CMS, Docker, Node.js |
| **Eleventy Quiz Game** | Interactive, data-driven web quiz application powered by static site templating. | 11ty, JavaScript, JSON, CSS3 |

## Key Architecture & Concepts
* **Static Site Generation (SSG)**: Fast pre-rendering and routing with Eleventy.
* **Templating Engines**: Reusable layouts and modular partials using Nunjucks (`_includes` / `.njk`).
* **Containerization**: Deploying scalable CMS environments using Docker.
* **Modern CSS Styling**: Responsive layouts built with CSS Grid, Flexbox, custom properties, and animations.
